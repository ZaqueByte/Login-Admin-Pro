# 🔐 Painel Admin Pro  
**Login & Cadastro Seguro em PHP**

Painel Admin minimalista, moderno e seguro, desenvolvido em **PHP**, com **PDO** e **Bootstrap 5**. Ideal para criar áreas administrativas restritas e aprender boas práticas de segurança.

## ⚙️ Funcionalidades
- 🔒 Hash seguro de senhas (`password_hash()` / `password_verify()`)  
- 🛡️ Proteção contra SQL Injection via **Prepared Statements (PDO)**  
- 🌐 Controle de sessões para acesso restrito (`$_SESSION`)  
- 💅 Interface moderna e responsiva com **Bootstrap 5**  

## 💻 Tecnologias
- PHP 7.4+  
- MySQL / MariaDB  
- PDO  
- Bootstrap 5.3  

## 🚀 Como Usar
1. Configure um servidor local (XAMPP, WAMP, MAMP).  
2. Crie o banco de dados `painel_admin` e a tabela `usuarios`.  
3. Ajuste as credenciais em `conexao.php`.  
4. Acesse `index.php` → Cadastre-se → Login → admin.php.  

> Sistema seguro e pronto para expansão com funcionalidades administrativas adicionais.
